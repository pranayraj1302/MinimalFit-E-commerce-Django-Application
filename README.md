# MinimalFit-E-commerce-Django-Application

Minimal Fit is a minimalistic e-commerce web application built using Django, HTML, CSS, and JavaScript. It focuses on providing a clean, straightforward shopping experience and demonstrates full-stack development capabilities using Django on the backend.

# About the Project
Minimal Fit allows users to:

1. Browse products across categories

2. View detailed product pages

3. Add products to a shopping cart

4. Review items in the cart and see the total

5. Complete checkout with a purchase summary

On the backend, the Django admin dashboard enables product, category, and order management.

# Features
- Homepage showcasing products

- Product category and detail pages

- Add to Cart and Remove from Cart

- Shopping cart summary and total calculation

- Checkout process

- Admin dashboard for product and order management

- Mobile-responsive design

- Frontend interactivity with JavaScript (such as cart updates)

# Tech Stack
- Backend: Django (Python), Django ORM

- Frontend: HTML, CSS, JavaScript

- Database: SQLite (default; can be upgraded to PostgreSQL or MySQL)

- Admin: Django Admin for management

# How It Works
The admin sets up products, categories, and prices using the Django admin interface.

Users browse products, add items to the cart, and complete the checkout process.

The backend tracks session-based carts, updates quantities, and calculates totals.

The frontend presents a clean, easy-to-navigate shopping interface.
